## Что проверено (`python leg_check.py`)

- Детали садятся на свои приводы без пересечений.
- Поворот основания ±60°: без столкновений. Стенка кронштейна стоит в 18,5 мм от оси основания, а угол корпуса привода основания — в 17,6 мм.
- Колено ходит −130…+30°. Сильнее не складывается: вилка голени ложится на пластины бедра. Пределы суставов прописать в приводы.
- Рабочая стойка (бедро +20°, колено −110°), покой «на корточках» (колено −125°) и **весь цикл шага с подъёмом стопы 25 мм** — без столкновений.
- Симуляция пересчитана с бедром 51 мм. Ходьба легче, чем было: на быстром шаге пик колена 1,87 вместо 2,40 Н·м, время выше номинала 7 вместо 14 %, запас устойчивости 21 вместо 17 мм. «Сесть — встать» работает.

## Покупное — добавилось

- Самонарезающие винты PA2.0 **на 1,5 мм длиннее штатных винтов корпуса** STS3215 — 8 шт. Ими заменяют задние винты корпуса привода бедра (4) и привода колена (4), винты проходят сквозь стенки обхватов.

## Обязательно измерить, когда придут приводы

1. **Разъёмы STS3215.** По чертежу даташита они на нижней стороне корпуса, в 7–17 мм от второго вала. Вставленный кабель может упереться в пластину бедра (привод бедра) и в ухо голени (привод колена). Если упирается — поставить привод разъёмами в другую сторону или взять угловые штекеры.
2. Размеры привода, фланца и положение винтов корпуса — значения с пометкой «ИЗМЕРИТЬ» в `harvey_leg_parts.py`. После правки:

        pip install manifold3d trimesh numpy
        python harvey_leg_parts.py        # пересоздаст stl/
        python leg_check.py               # полная проверка ноги

## Рендер

`python export_render_parts.py`, затем `blender --background --python render_legs.py`. Папка `render_parts/` — промежуточные файлы, их не печатать. На рендере — настоящая стойка `harvey_leg_tower`; на роботе привод основания держит панцирь.
