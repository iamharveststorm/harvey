# Харви — чертежи деталей

Чертежи по ГОСТ (лист A3, основная надпись, первый угол проекции), сделаны в FreeCAD 1.1 скриптом `harvey_drawings.py`. Размеры берутся из тех же скриптов, что делают STL, поэтому чертёж и печатная деталь совпадают. Скрипт сверяет объёмы с моделью STL и пишет итог в `_проверка.txt`.

| Чертёж | Деталь | Откуда параметры |
| --- | --- | --- |
| [[ХАРВИ.01.001 Рычаг 100 мм.pdf]] | рычаг 100 мм для замеров 3, 5, 7 | `модели/стенд ноги/harvey_leg_parts.py` |
| [[ХАРВИ.02.002 Ладонь кисти.pdf]] | ладонь кисти с нижним пальцем | `модели/стенд кисти/harvey_hand_parts.py` |

На каждом листе: главный вид, дополнительные виды по ГОСТ, изометрия, размеры и технические требования к печати.

## Другие файлы

- `Рычаг_100мм.step`, `Ладонь_кисти.step` — точные твёрдотельные модели, их можно импортировать в Onshape или любую САПР.
- `Харви_чертежи.FCStd` — исходник для FreeCAD: открыть, поправить вид или размер, выгрузить PDF вручную.

## Как пересобрать

После изменения размеров в скриптах деталей дважды щёлкните `make_drawings.bat`. Окно FreeCAD откроется на несколько секунд и закроется само: так он выгружает PDF.

## Шифры

`ХАРВИ.01.xxx` — стенд ноги, `ХАРВИ.02.xxx` — стенд кисти.
