# Голова «Компакт мини» — Pi Zero 2 W

Программа головы управляет глазами (2 круглых дисплея GC9D01), настроением, касаниями крышки и звуком. Связана с «спинным мозгом» RP2350 по USB и с «большим мозгом» на ПК по Wi-Fi. Без ПК голова живёт сама: пугается края и рук, радуется поглаживанию, устаёт, когда садится батарея, засыпает от скуки.

![[глаза_выражения.png]]

**ПРЕДВАРИТЕЛЬНО.** Выводы — по [[схемы/README|схемам]]. Всё проверено на ПК; дисплеи, кнопки и звук — на стенде.

## Как устроено

| Файл | Что |
| --- | --- |
| `eyes.py` | рисует глаз 160 × 160 по выражению (10 выражений), моргание, взгляд, плавные переходы; кадр — RGB565 для GC9D01 |
| `gc9d01.py` | драйвер дисплея: запуск по коду Waveshare, окно, кадр кусками ≤ 4096 байт; два глаза на SPI0 CE0 / CE1 |
| `mood.py` | события → выражение: испуг не перебивается мелочами, без событий — сонливость и сон |
| `touch.py` | 4 × TTP223: погладить (3 кнопки подряд за 1,2 с), коснуться (< 0,5 с), подержать (> 1,5 с) |
| `links.py` | RP2350 по USB и ПК по TCP; обрыв — переподключение через 1, 2, 4 … 30 с |
| `audio.py` | aplay / arecord для I2S (INMP441 × 2, MAX98357A), вывод SD усилителя |
| `head.py` | всё вместе: события → настроение → глаза; телеметрия на ПК 5 раз в секунду |
| `behavior.py` | поведение: телеметрия RP2350 + «зрение» → команда корпусу (осмотреться, к руке, у края, подняли, домой) |
| `protocol.py` | формат сообщений — общий с прошивкой (`код/прошивка/rp2350/link.py`) |
| `main.py` | запуск на Pi; `--sim` — без железа |
| `preview.py` | лист выражений и анимация (`глаза_выражения.png`, `глаза_анимация.gif`) |

Команды от ПК:
- `emote` — выражение на время;
- `look` — куда смотреть;
- `play` — проиграть звук;
- `j`, `relax`, `hold`, `cal` — голова передаёт их RP2350 как есть.

## Проверка на ПК

```bash
C:\venvs\harvey-head\Scripts\python.exe -m pytest -q tests
```

131 тест, < 1 с.
- **Глаза** сверяются с эталонными картинками `tests/golden/` до пикселя. После намеренной правки рисунка эталоны пересоздаёт команда `python -m tests.test_exact`.
- **Драйвер дисплея** проверяется на имитации SPI: команды при DC = 0, данные при DC = 1, полный код запуска из файла производителя.
- **Связь с ПК** проверяется на настоящем TCP-сервере: обмен в обе стороны и переподключение.

**Поведение** (`behavior.py`) проверяется на простом мире в самих тестах: корпус поворачивается и шагает ровно по
команде, гироскоп показывает этот поворот, маяк и метка станции — по геометрии. Как оно ведёт настоящего робота по его
датчикам — в симуляции: [[код/симуляция/мини/README|Симуляция мини]], раздел «Поведение по датчикам».

- Цели: «look» — осмотреться (6 остановок по 60°), «hand» — подойти к руке и встать в ~9 см, «home» — на станцию.
- Край стола: прочь от датчиков, под которыми пусто, ещё 0,5 с, разворот на 120° — и снова к цели.
- Подняли: стоять, пока все датчики края не видят стол 1 с подряд, потом осмотреться.
- Курс — по гироскопу (`tel["gyr"]`): повороты на угол, при ходьбе курс держится сам.
- Домой: по метке AprilTag выйти на ось станции в 25 см перед ней, идти прямо с поправками по метке; остановка — по
  передним датчикам края (площадка ближе стола, снова стол, башенка ближе), отступить на 17 мм, лечь. Нет заряда за 3 с —
  встать, отойти, повторить один раз. Без камеры — по ИК-маяку: найти сектор, где маяк видят оба приёмника, пройти его
  туда и обратно и встать на середину.

Качество кода: покрытие 89 %, без тестов только открытие настоящих дисплеев и `main`; самая сложная функция — 9, повторяющегося кода нет.

## Установка на Pi Zero 2 W (Raspberry Pi OS Bookworm Lite)

1. `sudo raspi-config` → Interface → включить SPI.
2. Звуковая карта I2S — в `/boot/firmware/config.txt`. Для пары INMP441 + MAX98357A обычно ставят `dtoverlay=googlevoicehat-soundcard`. **Проверить на стенде:** `arecord -l`, `aplay -l` и пробная запись.
3. Окружение:
   ```bash
   sudo apt install python3-venv python3-numpy python3-pil python3-spidev python3-gpiozero python3-lgpio alsa-utils
   python3 -m venv --system-site-packages ~/harvey && ~/harvey/bin/pip install pyserial
   ```
4. Репозиторий целиком (голове нужны `код/прошивка/rp2350/link.py` и файл запуска дисплея из `документы/`): `git clone` и запуск `~/harvey/bin/python -m harvey_head.main` из `код/голова`.

## Проверить на стенде

1. **Дисплеи.** Оба запускаются кодом Waveshare. Поворот картинки (`EYE_MADCTL`) — по тому, как дисплей стоит в стебельке. Нет ли мерцания при съёмке камерой: 3,3 В от Pi нагружены на ~0,35 А, см. [[схемы/README|схемы]], находка 8.
2. **Частота SPI.** Держит ли 32 МГц через провода в стебельке. Если нет — снизить `SPI_HZ`. 30 кадр/с на два глаза — это ~25 Мбит/с.
3. **TTP223.** Режим модуля — прямой выход без защёлки (перемычки A/B): 1 — пока касаются.
4. **Звук.** Имя устройства ALSA и уровень записи. Сигнал SD усилителя на GPIO26 гасит шипение, когда звука нет.
