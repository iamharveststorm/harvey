# Станция «Компакт мини» — ИК-маяк

MicroPython на RP2350-Zero. Два светодиода TSAL6200 по очереди шлют пачки 38 кГц:
- **левый** (+y, если смотреть, как Харви, на башенку) — пачка 0,6 мс;
- **правый** — пачка 1,2 мс;
- после каждой пачки пауза 0,6 мс.

Между светодиодами перегородка, поэтому оба видны только в узком клине вдоль оси станции. Харви различает пачки по длине импульса TSOP (`код/прошивка/rp2350/beacon.py`). Так он и без ПК, и в темноте понимает, куда повернуть и по какую сторону оси стоит.

**ПРЕДВАРИТЕЛЬНО.** Выводы и номиналы — по [[схемы/README|схеме beacon]], железа ещё нет.

| Файл | Что |
| --- | --- |
| `beacon_station.py` | расписание пачек и ШИМ 38 кГц (1/3) на GP0 / GP1 |
| `main.py` | запуск при включении питания |

## Почему такие числа

TSOP382 (документы/TSOP382 — даташит Vishay.pdf):
- пачка не короче 10 периодов, пауза не короче 12, не больше 1700 пачек в секунду — здесь 23 и 46 периодов, пауза 23, 667 пачек/с;
- на выходе длина пачки повторяется с точностью ±5/f0 = ±132 мкс (стр. 3), так что 0,6 и 1,2 мс не спутать: граница 0,9 мс.

Ключи AO3400A (документы/AO3400A — даташит AOS.pdf): Vgs(th) ≤ 1,45 В, открываются от 3,3 В вывода. Светодиод — 33 Ом от 5 В: ~110 мА в импульсе, в среднем ≤ 15 мА.

## Проверка на ПК

```bash
C:\venvs\harvey-bench\Scripts\python.exe -m pytest -q tests
```

5 тестов:
- светодиоды по очереди, никогда вместе;
- каждая пачка распознаётся кодом Харви (`beacon.code_of`) как свой светодиод;
- пределы TSOP382;
- хватает пачек на окно счёта Харви (100 мс).

## Залить на плату

1. Прошить MicroPython для RP2350.
2. Скопировать в корень платы `beacon_station.py` и `main.py` (Thonny → «Сохранить как… → Raspberry Pi Pico»).

## Проверить на стенде

- Длина пачек на выходе TSOP38238 — осциллографом или счётом Харви.
- Граница клина у настоящей перегородки: отражения от стола могут его расширить. Если так — резисторы светодиодов побольше.
- Не греются ли резисторы 33 Ом.
