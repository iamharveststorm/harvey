# Харви «Компакт мини» — симуляция

MuJoCo-модель мини. Размеры, массы и видимые детали взяты из CAD: [[модели/мини/README|Компакт мини — детали]]. Приводы — STS3032 с ограничением момента и падением момента со скоростью, как у настоящих. Физика считается по простым формам, детали CAD только рисуются.

## Запуск

```bash
python harvey_mini.py
```

Это все проверки, итог пишется в `mini_results.json`. Другие режимы:
- выборочные проверки: `python harvey_mini.py walk pen dock` (`stand`, `walk`, `turn`, `pen`, `wipe`, `tip`, `edge`, `dock`);
- `python harvey_mini.py --view` — окно MuJoCo, Харви идёт;
- `python mini_photo.py` — фотореалистичные кадры на рабочем столе (Filament); нужен MuJoCo 3.15+.

После правок CAD сначала запустите `C:\venvs\harvey-cad\Scripts\python.exe модели/мини/harvey_mini_parts.py` — это обновит `assets/`.

## Управление с клавиатуры (фотореалистично)

Двойной клик по `run_mini_windows.bat` или `python harvey_mini_teleop.py`; простое окно MuJoCo — `--classic`, самопроверка без окон — `--test`.

![[mini_управление.png]]

**Сцена.** Тот же рабочий стол, что у «Компакта», в реальном масштабе 1 : 1: ручки, карандаш, блокнот, кружка, кейс наушников, зажигалка, книга, ноутбук, лампа. Ещё есть салфетка перед левой клешнёй и станция зарядки на столе слева сзади.

**Картинка** — рендер Filament: PBR-материалы, текстуры Poly Haven, мягкие тени, около 30 кадров/с на RTX 5070 Laptop. Физика — MuJoCo в отдельном процессе, с теми же приводами STS3032, что в проверках.

| Клавиши | Что делают |
| --- | --- |
| W / S, A / D, Q / E (зажать) | вперёд / назад, поворот, шаг вбок |
| F | быстрый шаг |
| R | присесть (для работы на столе) |
| Z | лечь на брюхо |
| Пробел | стоп |
| B | выбрать клешню: левая / правая / обе |
| I / K, J / L, U / O (зажать) | клешня вперёд / назад, влево / вправо, вверх / вниз |
| N / M | раскрыть / сжать губки |
| 1 / 2 / 3 / 4 | поджать / к столу / помахать / подать |
| T | взять ручку или карандаш перед выбранной клешнёй (предмет должен лежать вдоль клешни) |
| H | домой: дойти до станции в обход башенки и лечь на контакты |
| 7 / 8 / 9 | глаза: грусть / интерес / радость |
| G | защита края стола вкл/выкл |
| C | показать физические формы |
| 0 | начать заново |
| X / Esc | выход |

Мышь в фото-окне: левая кнопка — вращать, правая или колесо — приблизить. Клешни двигаются только в пределах правил движения из CAD: на запретную позу панель пишет «предел клешни».

**Батарея — модель 22 Вт·ч.** Ток каждого привода считается по его моменту (у STS3032-C036 0,44 Н·м при 1,2 А). Сверху — 1,8 Вт на Pi Zero, дисплеи и датчики. На станции, когда оба контакта прижаты, батарея заряжается мощностью 12 Вт. Заряд показан на панели.

**Самопроверка (`--test`):**
- ходьба, поворот, шаг вбок, клешни работают;
- T — ручку взял, поднял на 75 мм, подал на высоте 106 мм;
- H — дошёл до станции в обход башенки и лёг на контакты с точностью 1 мм, заряд растёт;
- шаг вбок к краю — остановился в 37 мм от края (по средней стопе).

**Боковые датчики края.** Их луч наклонён положе, чем у передних: 3,5 : 1, около 16° вниз, а у передних 2,3 : 1. Так край виден за 100 мм, потому что средние стопы выходят за корпус на 57 мм. С наклоном 2,3 : 1 запас был бы всего 12 мм.

## Почему MuJoCo + Filament, а не другой движок

| Движок | Картинка | Физика маленького робота | Для нас |
| --- | --- | --- | --- |
| **MuJoCo + Filament** (сейчас) | PBR, мягкие тени, ~30 к/с | лучшая для приводов и контактов; на ней проверены ходьба и захват | ✅ уже работает |
| NVIDIA Isaac Sim (PhysX 5 + RTX) | трассировка лучей, почти фото | хорошая, для роботов | возможно; 8 ГБ видеопамяти — на нижней границе, установка ~20 ГБ |
| Unreal Engine 5 / Unity HDRP | лучшая (Lumen, HDRP) | игровая (Chaos, PhysX): контакты мелких приводов неточны | только как «картинка» для физики MuJoCo — плагин MuJoCo для Unity |
| Genesis | трассировка лучей | быстрая, на GPU | молодой проект, мало проверен |
| Gazebo / Webots | средняя | хорошая | не красивее Filament |

Если захочется «как в кино» в реальном времени, следующий шаг — Isaac Sim или связка MuJoCo + Unity. Физика при этом остаётся проверенной.

## Результаты (масса 893 г из CAD)

| Проверка | Итог |
| --- | --- |
| Стойка | бедро 24 % номинала STS3032, просвет под корпусом 22 мм |
| Ходьба трипод | 6,2 см/с, увод 4 мм за 8 с, наклон ≤ 0,4°; бедро в среднем 76 % номинала, пики 74 % предела; колено 50 % |
| Разворот на месте | 45°/с |
| Ручка | присел на 16 мм, губки сверху, сжал, поднял на 68 мм, пронёс 2 с шагом, подал на высоте 105 мм — в пальцах; правила не нарушены; подъём плеча 13 % номинала |
| Протирка салфеткой | губки прижимают салфетку, рука ходит вперёд-назад, полосы смещаются разворотом корпуса; салфетка ходит за рукой (45 мм), правила не нарушены |
| Клешни вперёд | не клюёт носом (наклон 0,1°) |
| Край стола | передний датчик видит край за 67 мм до корпуса; запас до края у стопы 42 мм, у клешни 38 мм |
| Станция зарядки | 20 см шагом за 3,2 с, промах 6 мм вперёд и 2 мм вбок, опустился на 13 мм; на контактах 3,6 и 4,0 Н — заряжается |

**Что это значит для приводов.** При ходьбе бедро нагружено в среднем на ~76% номинала. Ходить можно, но долго без отдыха привод будет греться. Поэтому Харви ходит перебежками и отдыхает лёжа на брюхе. На стенде проверить нагрев STS3032 за 10 минут ходьбы.

**Что это значит для станции.**
- Промах вбок допустим до 4 мм: пластины на брюхе 40 × 12 мм, контакты Ø5.
- В симуляции Харви шёл к станции вслепую, по известному положению. На роботе путь подправляется по метке AprilTag на башенке (камера, ПК) или по ИК-маяку (без ПК).
