# Харви — управление в симуляции

Симуляция робота-краба Харви (спецификация v1.0: клешни с пятью суставами и хвост с присоской; с 15.10 — компоновка v2: плечи клешней в (105; ±30) мм, кисть с отогнутыми пальцами, глаза-стебельки на углах, рама вместо коробки, реальные пределы суставов, см. [[модели/корпус/README|корпус и компоновку]]) в физическом движке MuJoCo. Можно водить его по столу с клавиатуры, брать телефон хвостом и класть себе на спину, переворачивать и пробовать вставать, а также прогонять проверки.

## Быстрый старт

Нужен Python 3.10–3.14 (python.org) и интернет для первой установки, MuJoCo 3.15 или новее. Для обычного окна видеокарта не нужна; режиму «фото» желательна дискретная.

| Система | Что запустить |
| --- | --- |
| Windows | двойной клик по `run_windows.bat`; фотореалистичное окно — `run_photo_windows.bat` |
| Linux | `./run_linux.sh` в терминале |
| macOS | двойной клик по `run_mac.command` (или в терминале) |

Скрипт сам создаст окружение Python (на Windows — в `C:\venvs\harvey`, вне OneDrive; другой путь можно задать переменной `HARVEY_VENV`; на Linux/macOS — папку `.venv` рядом со скриптами), установит MuJoCo и numpy (первый раз около минуты) и откроет окно симуляции.

Рядом с окном симуляции откроется **панель управления** — маленькое окно поверх остальных. Кнопки на ней работают всегда, даже если вы крутили камеру мышью в окне симуляции. Клавиши работают, когда активна панель (кликните по ней), в любой раскладке. Ходьба — пока клавиша или кнопка зажата: отпустили — Харви остановился.

## Режим «фото» — фотореалистичная картинка

`python harvey_teleop.py --photo` (на Windows — `run_photo_windows.bat`). Вместо обычного окна MuJoCo открывается окно с рендером **Filament** (входит в MuJoCo 3.15): физически корректные материалы (цвет + карты нормалей + шероховатость с Poly Haven), мягкие тени, освещение от окружения, сглаживание. Панель и клавиши те же; клавиши работают и в окне «фото». Камера: левая кнопка мыши — вращать, правая или колесо — приблизить. Около 27 кадров в секунду на RTX 5070 Laptop.

Физика в этом режиме идёт в **отдельном процессе**, окно — в основном: Filament и поток физики в одном процессе иногда роняли программу, а так оба ядра работают параллельно. Следы на песке подгружаются в картинку раз в 1,5 с (на долю секунды картинка замирает).

## Физика веществ

Модуль `harvey_terrain.py`; всё считается вместе с роботом, в реальном времени.

- **Песок** — деформируемый грунт: карта высот 221 × 181 ячеек по 5 мм, которую программа меняет во время симуляции. Несущая способность растёт с глубиной: q(z) = 4 кПа + 4 МПа/м · z, площадь опоры сферической стопы — π(2rz − z²). Пока стопа давит сильнее, песок продавливается (до 0,24 м/с). Вытесненный песок ложится валиком вокруг следа — объём сохраняется точно. Склоны круче 33° (угол естественного откоса) осыпаются. Стопа, идущая вбок, пашет борозду. Итог: стоя Харви проседает на 6–9 мм, за ним остаётся цепочка следов, а стенки следов дают ногам упор — боковое сползание на дюнах уменьшилось.
- **Гравий и галька** — настоящие отдельные камни (240 гравийных 12–22 мм и 150 галек 24–40 мм, эллипсоиды, плотность гранита 2600 кг/м³), насыпанные на неровное основание. Пока их никто не трогает, они «спят» (режим сна MuJoCo) и почти не тратят время; стопа их будит — камни раскатываются и проворачиваются под ногой. Если поменяете полосу — `python harvey_terrain.py --settle` заново уронит камни и запомнит, как они улеглись.
- **Трава** — 950 пучков по 24 стебля (видны, сквозь них можно пройти) и сопротивление: стопа в слое стеблей (35 мм) тормозится силой 0,8 Н·с/м × скорость × глубина погружения; дёрн под ними мягкий.
- **Стол, предметы, доска, склоны** — твёрдые тела с трением как раньше; предметы на столе тоже «спят», пока их не тронут.

## Адаптивная походка

Включена по умолчанию; V — выключить/включить (сравнить со старой). Тот же алгоритм пойдёт в Pico 2:

1. **Корпус ровно по IMU** — на склоне ноги снизу вытягиваются, сверху поджимаются.
2. **Поиск опоры** — опорная нога без контакта опускается, пока не нащупает землю (до −45 мм); нога в переносе, коснувшаяся раньше (ступенька, камень), останавливается там. На роботе касание — по нагрузке привода колена (регистр Present Load STS3215).
3. **Шаг выше и медленнее** на неровном и крутом.

Проверка (5 с ходьбы в каждой зоне, старая → адаптивная): средний наклон корпуса на склонах 5–9° → 0,3–3,6°; склон 20° — 334 → 421 мм пути, 25° — 239 → 338 мм; ступени — наклон до 4,2° → 1,6°; косой склон 15° — сползала назад → идёт вперёд ровно. На деформируемом песке от края площадки (дюны поперёк хода) — 380 мм вперёд, снос вбок 90 мм; в середине площадки — 528 мм и 4 мм.

## Управление

| Клавиша | Действие |
| --- | --- |
| W / S (зажать) | вперёд / назад |
| A / D (зажать) | повернуть влево / вправо |
| Q / E (зажать) | шаг вбок влево / вправо |
| Пробел | стоп и отмена текущего действия хвоста |
| F | быстрый / обычный шаг |
| R | лечь / встать |
| 1 / 2 / 3 / 4 | клешни: сложить / к столу / на спину / вверх |
| B | клешня для ручного управления: левая / правая / обе |
| I / K (зажать) | кончик клешни вперёд / назад |
| J / L (зажать) | влево / вправо (обе клешни — зеркально: врозь / вместе) |
| U / O (зажать) | вверх / вниз |
| N / M | открыть / сжать пальцы; сжатые пальцы, коснувшиеся предмета обеими накладками, держат его |
| 5 | вернуться на стол |
| ] / [ | следующая / предыдущая зона полосы препятствий |
| G | защита края стола вкл/выкл (выключите, чтобы сойти по доске) |
| C | показать физические формы вместо деталей |
| V | адаптивная походка вкл/выкл |
| T | хвост берёт телефон позади и кладёт на спину (развернитесь к нему задом) |
| Y | попробовать встать со спины — удаётся не всегда |
| P | опрокинуть Харви на спину, чтобы проверить |
| 0 | начать заново |
| X / Esc | выход |

Мышью в окне симуляции: левая кнопка — вращать вид, правая — сдвигать, колесо — масштаб. Камера следует за Харви.

**Мир.** Харви стоит на рабочем столе в комнате (окно, тёплая настольная лампа, тени). На столе: телефон (позади Харви — для хвоста), ручки, карандаш, блокнот, кружка с кофе, кейс наушников, зажигалка, стикеры, книга, ноутбук. Датчики края (как будет на Pico) не дадут сойти со стола, пока защита края включена. С переднего края стола — доска-спуск 20° на пол, где полоса препятствий: трава (кочки и стебли), песок (дюны, продавливается, остаются следы), гравий и галька (отдельные камни), склоны 10°/15°/20°/25°, косой склон 15°, ступени 15/30/45 мм, асфальт с кабелем и книгами. В зоны можно перенестись клавишами ] и [. Харви нарисован настоящими деталями из CAD; физика считается по простым формам (C — показать их). Текстуры — Poly Haven (CC0); если папки `assets/` нет, откроется простой стол.

**Глаза.** При опрокидывании Pico сразу складывает глаза наружу до упора (−105°): на спине Харви лежит на хвосте, а дисплеи не касаются стола; при падении через нос удар по дисплеям — 0 Н. При падении **вбок** глаз сложить не успеть (падение 0,1–0,2 с, глаз складывается 0,35–0,9 с): тут защищают магнитная муфта (глаз отскакивает) и бампер из TPU. Проверка: `python harvey_protect.py`. Пока хвост выполняет действие (T, Y), ходьба не работает — панель пишет «занят»; пробел прерывает действие.

**Попробуйте:** T — хвост возьмёт телефон со стола позади и положит на спину; потом W, A, R — телефон не должен съехать. P, затем Y — Харви попробует встать со спины.

## Проверки

- Windows: `run_tests_windows.bat`; Linux: `./run_linux.sh --test`.
- Вручную (внутри окружения): `python harvey_teleop.py --test` — сценарий управления без окон; `python harvey_teleop.py --gui-test` — самопроверка панели (нажимает кнопки сама); `python harvey_sim.py` — базовые тесты клешней и ходьбы; `python harvey_scenarios.py all` — все сценарии (поверхности, препятствия, край стола, уклоны, толчки, отказ ноги, батарея, разброс параметров, протирка). Результаты пишутся в `scen_*.json`.
- Сверка во втором движке: `pip install -r requirements-extra.txt`, затем `python harvey_pybullet.py`. PyBullet под Python 3.12+ может собираться из исходников 10–15 минут, на Windows для этого нужны Build Tools; это необязательно.

## Если что-то не так

- **«Не найден Python»** — установите Python 3.10–3.14 и при установке отметьте «Add python.exe to PATH».
- **Режим «фото» не открывается** — нужен MuJoCo 3.15+ (`pip install -U mujoco`) и драйвер видеокарты с OpenGL 4.5; обычное окно (`run_windows.bat`) работает и без этого.
- **macOS: окно не открывается** — запускайте через `mjpython harvey_teleop.py` (так делает `run_mac.command`); обычный `python` на macOS окно MuJoCo не откроет.
- **Клавиши не работают** — кликните по панели управления (кнопки на ней работают и без этого). Если панели нет совсем, запустите `python harvey_teleop.py --console` — тогда клавиши нажимаются в консоли, а ходьба идёт до следующей команды.
- **Linux: нет панели** — установите `python3-tk` (`sudo apt install python3-tk`).
- **Симуляция идёт медленнее реального времени** — это нормально на слабом процессоре: физика считается на одном ядре с шагом 0,5 мс. На поведение робота это не влияет.
- **Linux: ошибка OpenGL/GLFW** — установите драйверы видеокарты и пакет `libglfw3`.

Это симуляция с упрощённой моделью: она проверяет размеры, нагрузки и поведение, но не люфт шестерён, нагрев и посадку разъёмов — это покажет стенд с настоящими деталями. Песок — инженерная модель (несущая способность + откос), а не просчёт каждой песчинки: это в реальном времени на ноутбуке невозможно. Порог продавливания подобран под сухой рыхлый песок; на стенде стоит сверить с настоящей ногой в песочнице.
