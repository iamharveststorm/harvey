# «Большой мозг» Харви на ПК

Этап A: вся логика голоса без звука (текстовый режим). Только stdlib; Ollama должна быть запущена (`http://127.0.0.1:11434`).

## Запуск
```
cd код/мозг
C:\venvs\harvey-head\Scripts\python.exe -m harvey_brain --text [--model M] [--port 8765] [--no-head]
```
Фразы — с клавиатуры; пустая строка дважды или Ctrl+C — выход. `--no-head` — без сервера для головы.

## Что понимает
- Без слова «Харви» (харви, харвей, harvey, wake up Harvey) Харви молчит; после ответа 8 с слушает без него.
- Быстрые команды (без LLM): «домой / на зарядку» -> home; «посмотри на меня» -> look; «иди ко мне / к руке» -> hand; «стоп / отдыхай» -> idle.
- Остальное — LLM; ответ JSON `{say, emote, goal}`, говорит не больше 2 предложений / 300 символов. Ollama молчит — «Ой, я задумался и потерял мысль.».
- События головы: `lifted`, `docked`, `bat_low` (не чаще раза в 20 с).

## Протокол с головой
TCP, порт 8765, одна строка — один JSON (формат `код/прошивка/rp2350/link.py`). Голова (`harvey_head.links.BrainLink`) подключается сама.
Мозг -> голова: `{"t":"emote","name":"happy","s":3.0}`, `{"t":"goal","goal":"home"}` (look, hand, home, idle).
Голова -> мозг: `{"t":"ev","ev":"lifted|docked|bat_low"}`.

## Модель по умолчанию
Замер 2026-11-04 (5 фраз, тёплая модель): `qwen3.6:35b` ~2,2–3,2 с, `dolphin3:8b` ~0,6–1,1 с; русский у обоих нормальный, у qwen теплее и живее. Выбран `qwen3.6:35b`; холодный старт ~27 с (загрузка 22 ГБ), `keep_alive` 30 мин. Если медленно — `--model dolphin3:8b`.
