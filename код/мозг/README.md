# «Большой мозг» Харви на ПК

Логика диалога — только stdlib; голос (этап B) — sherpa-onnx, sounddevice, numpy. Ollama должна быть запущена (`http://127.0.0.1:11434`).

## Запуск
```
cd код/мозг
C:\venvs\harvey-brain\Scripts\python.exe -m harvey_brain --text [--model M] [--port 8765] [--no-head] [--home PATH]
```
Фразы — с клавиатуры; пустая строка дважды или Ctrl+C — выход. `--no-head` — без сервера для головы.

## Голос (этап B)
Окружение: `C:\venvs\harvey-brain` (Python 3.14, `pip install -r requirements.txt`; sherpa-onnx закреплён на 1.13.8 — в Windows-колесе 2.0.1 Piper/espeak не работает).

**Модели** — вне репозитория, в `~/.harvey/models` (или `--models PATH`, или переменная `HARVEY_MODELS`). Путь только латиницей: espeak-ng в Windows не открывает кириллические пути (иначе мозг выходит с сообщением). Скачать недостающее: `python get_models.py [--models PATH]` (silero_vad.onnx, GigaAM v2 русский, Piper ru_RU dmitri medium, YuNet для лиц `vision/face_detection_yunet_2023mar.onnx` из opencv_zoo; существующее пропускается; файл меньше 100 КБ отвергается как указатель Git LFS).

```
python -m harvey_brain --mic [--no-head]          # слушать микрофон, отвечать вслух
python -m harvey_brain --text --voice [--no-head]  # фразы с клавиатуры, ответ вслух
```
- Микрофон: моно 16 кГц (если устройство не умеет — его частота + пересчёт), окно 512; Silero VAD порог 0,5, тишина 0,5 с, речь от 0,25 с, до 10 с; каждый кусок речи — в GigaAM, текст идёт в диалог (в консоли «Слышу: …»).
- Полудуплекс: пока Харви говорит, слух выключен; через 0,4 с после конца речи буфер VAD сбрасывается и слух возвращается — Харви не слышит сам себя. Ctrl+C — чистый выход.
- GigaAM часто слышит «Харви» как «карви / корве / харбе / фарви…». Имя ищется по звучанию (`wake.sound_key`: х к г ф, в б, а о, и е й ы э — по классам, повторы сливаются; ключ KARVI), плюс «harvey» и «wake up / вейк ап» перед именем. Команда после имени распознаётся надёжно.

**Живая проверка (делает пользователь, звук в тестах не включается):**
1. `python -m harvey_brain --mic --no-head`; сказать «Харви» — ответ «Да?».
2. «Харви, посмотри на меня» — в консоли `look`, ответ вслух, без эха самого себя.
3. «Харви, иди домой» — цель `home`.
4. Минуту посторонний разговор / ТВ рядом — ложных пробуждений должно быть 0 (если есть — поднять порог VAD в `make_vad` или добавить слову строгости).
5. Выбор устройства: `python -c "import sounddevice; print(sounddevice.query_devices())"`.

## Звук и картинка головы (`--head-audio`)
```
python -m harvey_brain --head-audio [--media-port 8766] [--models PATH]
```
Слушают микрофоны головы, говорит её динамик; распознавание, LLM и голос Piper остаются на ПК. Мозг печатает «Жду голову…», пока она не подключилась. Второе TCP-соединение, порт 8766 (брандмауэр Windows порт разрешить самому), двоичные кадры (формат — `код/голова/harvey_head/media.py`); команды на 8765 не меняются. `MediaServer` (`media_server.py`): `audio` (PCM int16 16 кГц, кадры по 20 мс; очередь до 10 с, старое выбрасывается), `latest_frame()` (время приёма и JPEG камеры), `request_video(on, fps)` (видео по умолчанию выключено), `send_speech(pcm, rate)`, `head_speaking`, `connected`. `RemoteMicListener` и `RemoteSpeaker` (`speech.py`) — те же VAD, GigaAM и Piper, что у `--mic`; полудуплекс делает голова (микрофон молчит, пока она говорит, и 0,3 с после). Железо в тестах не открывается: ни микрофон, ни динамик, ни камера. Живая проверка — на стенде (см. README головы).

## Зрение: лица (`--vision head|webcam|off`)
Харви находит лицо в кадре и следит за ним глазами. Кто это — не узнаёт, только «есть лицо». `vision.py`: детектор YuNet (`cv2.FaceDetectorYN`, порог 0,8), чистая геометрия и `Watcher`.
- Окружение: `opencv-python-headless==5.0.0.93` (`requirements.txt`). Модель — вне репозитория: `~/.harvey/models/vision/face_detection_yunet_2023mar.onnx` (папка моделей та же: `--models` / `HARVEY_MODELS`, путь ASCII). Тестовые картинки там же в `vision/test/` (`messi5.jpg` — одно лицо, `fruits.jpg` — лиц нет); тесты с моделью пропускаются, если файлов нет.
- `--vision head` (по умолчанию вместе с `--head-audio`): кадры камеры головы (`MediaServer.latest_frame()`, серый JPEG 1280 × 720); при подключении мозг просит `request_video(True, 5)`. Кадр старше 1 с не считается — голова отключилась, значит лица «сейчас» нет. `--vision webcam`: камера ноутбука (`cv2.VideoCapture(0)`) — проверяет пользователь сам, в тестах камера не открывается. Модели нет: у `--vision` без явной просьбы зрение молча выключается (сообщение в консоли), с явной — выход с кодом 2.
- Цикл 5 раз в секунду: кадр -> лица -> `Watcher`. Следит за самым крупным лицом; глазам идёт `{"t":"look","x","y"}` (x вправо, y вверх, в [-1, 1]), не чаще 5 раз в секунду, сглаженно; мигание лица в 1–2 кадра не в счёт: «пропало» только после 3 с без лица (тогда один `look` 0, 0).
- «Привет!» (с именем из памяти — «Привет, Аня!») — когда лицо появилось, а прошлый раз его видели ≥ 10 минут назад или никогда; обычный ответ (голос, глаза `happy`).
- «Харви, посмотри на меня», когда лицо видно: голове `{"t":"turn","deg":азимут лица}` и ответ «Смотрю на тебя!»; голова поворачивается корпусом на месте по гироскопу (цель `turn`, короткой дорогой, потом покой). Лица не видно — осмотреться (`look`), как раньше. Знаки углов как у метки станции: + — налево, лицо в правой половине кадра — минус.
- Камера Wide и её смещение от центра корпуса (66 мм) — ПРЕДВАРИТЕЛЬНО: точность азимута проверить на роботе (калибровка камеры — см. `dock_tag.py`).

## Что понимает
- Без слова «Харви» (харви, харвей, harvey, wake up Harvey) Харви молчит; после ответа 8 с слушает без него.
- Быстрые команды (без LLM): «домой / на зарядку» -> home; «посмотри на меня» -> look; «иди ко мне / к руке» -> hand; «стоп / отдыхай» -> idle.
- Помощник (без LLM и интернета, `assistant.py`): «который час», «какое сегодня число»; «таймер на десять минут» (без длительности спросит «На сколько поставить таймер?» — отвечать можно без «Харви», 30 с), «засеки полторы минуты»; «напомни через полчаса выключить чайник», «напомни в 18:30 / в 7 вечера позвонить маме» (если время уже прошло — завтра); «сколько осталось», «отмени таймер» (ближайший), «отмени все таймеры»; «меня зовут Аня», «как меня зовут», «запомни, что я люблю чай», «что ты обо мне знаешь», «забудь всё обо мне». Числа — словами и цифрами (`numbers.py`: «двадцать пять минут», «пару минут», «полтора часа»).
- Сработавший таймер или напоминание Харви произносит сам, даже если «спит» («Динь! Прошла 1 минута.», «Напоминаю: позвонить маме.»), после этого 8 с слушает без «Харви». Выключали Харви — при запуске напоминание, время которого прошло, говорится как «Пока меня не было: …» и один раз.
- Остальное — LLM; ответ JSON `{say, emote, goal}`, говорит не больше 2 предложений / 300 символов. Ollama молчит — «Ой, я задумался и потерял мысль.».
- События головы: `lifted`, `docked`, `bat_low` (не чаще раза в 20 с).

## Память
Файл `memory.json` (имя, факты, таймеры) лежит вне репозитория: `~/.harvey/memory.json`; другая папка — `--home PATH` или `HARVEY_HOME`. Запись атомарная (временный файл + замена); битый файл откладывается в `memory.json.broken`, память начинается пустой. Имя и до 20 последних фактов добавляются вторым системным сообщением LLM. Стереть: сказать «забудь всё обо мне» (таймеры остаются) или удалить файл.

## Протокол с головой
TCP, порт 8765, одна строка — один JSON (формат `код/прошивка/rp2350/link.py`). Голова (`harvey_head.links.BrainLink`) подключается сама.
Мозг -> голова: `{"t":"emote","name":"happy","s":3.0}`, `{"t":"goal","goal":"home"}` (look, hand, home, idle), `{"t":"look","x":0.3,"y":0.1}` (куда смотреть глазам), `{"t":"turn","deg":-20}` (повернуться на месте на угол, + — налево).
Голова -> мозг: `{"t":"ev","ev":"lifted|docked|bat_low"}`.

## Модель по умолчанию
Замер 2026-11-04 (5 фраз, тёплая модель): `qwen3.6:35b` ~2,2–3,2 с, `dolphin3:8b` ~0,6–1,1 с; русский у обоих нормальный, у qwen теплее и живее. Выбран `qwen3.6:35b`; холодный старт ~27 с (загрузка 22 ГБ), `keep_alive` 30 мин. Если медленно — `--model dolphin3:8b`.

## Тесты
`python -m pytest -q tests` из `код/мозг` (C:\venvs\harvey-brain). Тесты с моделями пропускаются, если папки моделей нет; настоящие микрофон и динамик в тестах не открываются. Синтез Piper в тесте детерминированный (`noise_scale=0`): обычный синтез каждый раз звучит чуть иначе, и распознавание имени «Харви» плавает.
