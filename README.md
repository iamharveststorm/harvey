# Папка проекта Харви

Распакуй в удобное место (например `C:\\Users\\ИМЯ\\Projects\\harvey`),
открой папку `harvey` в Obsidian как хранилище и запускай Claude Code в ней же.

## Что внутри
- `заметки/` — концепция, журнал решений и 5 документов проекта (бюджет, совместимость,
  питание, сборка в Onshape, этап 1).
- `визуализация/` — 3D-модель и интерактивный двойник. Открываются двойным кликом в браузере,
  three.js лежит в `lib/`, интернет не нужен (кроме шрифтов).

## Чего здесь нет — докинь из чатов вручную
Эти файлы выдавались прямо в чатах, а не артефактами, поэтому в архив не попали:
- `код/симуляция/`: `harvey_sim.py`, `harvey_scenarios.py`, `harvey_pybullet.py`
  (и скрипт с управлением с клавиатуры, если он был отдельным файлом);
- `модели/`: `Harvey_leg_CAD.zip`, `harvey-stage1-parts` (STL/STEP деталей стенда).
