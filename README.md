# Харви — настольный робот-краб

DIY-робот для рабочего стола: компаньон и помощник с добрым характером. Шесть ног, две клешни, глаза-дисплеи. Мозг для речи и зрения работает на домашнем ПК, робот связан с ним по Wi-Fi.

**Начни с [Харви](<Харви.md>)** — там все заметки, модели, код и текущий этап.

## Как открыть

- **Obsidian:** «Открыть папку как хранилище» → эта папка. Главная заметка — «Харви».
- **Claude Code:** запускать в этой папке; контекст проекта — [CLAUDE.md](<CLAUDE.md>).
- **Окружения Python** живут вне OneDrive, в `C:\venvs\` (`harvey` — симуляция, `harvey-bench` — стенд, `harvey-cad` — CAD). Первые два батники в папках кода создают сами; как запускать CAD — в README папок `модели/`.
