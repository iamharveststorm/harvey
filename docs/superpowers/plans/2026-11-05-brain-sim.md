# Мозг ведёт Харви в симуляции — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пользователь набирает в окне мозга «Харви, иди домой» — Харви в окне MuJoCo идёт к станции; «Харви, посмотри на меня» — осматривается; «иди ко мне» — идёт к руке; эмоции ответа видны (глаза в консоли и картинкой). Вся цепочка настоящая: мозг (`harvey_brain`, TCP :8765) → голова (`Head` + `Body`, как на Pi) → прошивка RP2350 (`Spine` в `SimRobot`) → робот.

**Architecture:** Новый скрипт `код/симуляция/мини/mini_brain.py`. Голова в симуляции подключается к мозгу настоящим `harvey_head.links.BrainLink`, который крутится в отдельном потоке со своим asyncio-циклом (`ThreadedBrain`: `poll()` и `offer()` потокобезопасны). Цикл симуляции — как `mini_behave.run`: физика, голова 50 раз в секунду, перед каждым тиком головы — сообщения мозга в `Head.on_brain`; темп — реальное время (кроме `--fast`). Мозг — отдельный процесс в своём окне (`harvey-brain` venv), его запускает сам `mini_brain.py --with-brain` (пути с кириллицей — из Python, не из .bat).

**Tech Stack:** Python, MuJoCo (venv `C:\venvs\harvey`), asyncio + threading, `harvey_brain` (stdlib-часть: `server.py` для тестов).

**Spec:** этот документ; решения — ведущего.

## Global Constraints
- Голову, прошивку и мозг не менять, кроме явно названного ниже. Если без правки не обойтись — эскалация, не тихая правка.
- `.bat` — только ASCII и CRLF; путь к `код/мозг` вычисляет Python.
- Тесты — `C:\venvs\harvey\Scripts\python.exe -m pytest -q tests` из `код/симуляция/мини`; все прежние тесты симуляции зелёные; окно MuJoCo в тестах не открывается.
- Пути вне своей папки (`код/голова`, `код/мозг`) — и как есть, и через `resolve()`.
- Код — по `.claude/skills/ub-mode/SKILL.md` (падающий тест первым).

## Review Focus
1. Мозг не запущен — симуляция работает, голова ведёт себя сама (как без ПК), раз в 5 с пробует подключиться; в консоли «мозг не на связи» один раз, а не каждый тик (задача 1).
2. Мозг закрыли посреди пути домой — Харви продолжает идти домой (цель уже у головы), без падения скрипта (задача 2).
3. Цель «hand» на сцене без руки — Харви осматривается и не падает со стола (задача 2: в сцене рука есть всегда, тест — что она видна из старта).
4. Две команды подряд («иди домой», через 2 с «стоп») — вторая отменяет первую (`idle`) (задача 2).
5. Закрыли окно MuJoCo — поток связи и окно мозга (если запускали `--with-brain`) закрываются, процесс не висит (задача 3).
