# Домой без ПК и в темноте — план

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Харви сам находит станцию и ложится на контакты без ПК: при свете — по метке AprilTag (разбор кадра на голове), в темноте — по двум ИК-светодиодам станции с разными пачками.

**Architecture:** голова (Pi Zero 2 W) распознаёт метку OpenCV ArUco (словарь AprilTag 36h11) и считает, где корпус в системе станции. Станция: RP2350-Zero шлёт по очереди пачки 38 кГц на левый (0,6 мс) и правый (1,2 мс) светодиоды, между ними перегородка — оба видны только в узком клине вдоль оси. RP2350 Харви различает пачки по длине импульса TSOP; третий приёмник по центру (GP28) говорит, по какую сторону оси корпус. Поведение: в темноте — направление по боковым приёмникам, сторона оси — по центральному.

**Spec:** запрос пользователя 03.11.2026 — «и в темноте тоже, делай метку и два светодиода».

## Global Constraints
- Числа: Camera Module 3 Wide — f 2,75 мм, пиксель 1,4 мкм, 4608 × 2592, поле 102° × 67° (документы/Camera Module 3 — краткое описание.pdf); TSOP382 — tpo = tpi ± 5/f0, tpi ≥ 10/f0 (стр. 3); TSAL6200 — как раньше. Метка 30 × 30 мм, центр (140; 0; 30) мм от центра площадки (CAD dock_tower).
- Пачки: левый 0,6 мс (23 периода), правый 1,2 мс (46), пауза 0,6 мс, по очереди; граница распознавания 0,9 мс. Скважность и рис. 8 даташита — проверить на стенде.
- Прошивки — MicroPython, проверка на ПК тестами; железо — «предварительно».

## Tasks
1. **Голова: `dock_tag.py`** — `camera_matrix`, `detect(gray)`, `body_in_station(corners, K)`; тесты на синтетических кадрах (метка нарисована в кадре по известной позе) — ошибка ≤ 3 мм и ≤ 1° до 35 см.
2. **Станция: `код/прошивка/станция/`** — `beacon_station.py`: расписание пачек (чистая функция) + PIO-несущая 38 кГц; тесты расписания.
3. **Харви: `beacon.py`** — длина импульса → код L / R, три приёмника (слева, по центру, справа); телеметрия `ir`; `pins.IR_CENTER = 28`.
4. **Симуляция** — два светодиода с перегородкой, тень по геометрии, коды, три приёмника; тесты.
5. **Поведение** — в темноте: поиск по маяку → центрирование → заход с поправкой вбок по центральному приёмнику; сценарии «в темноте» 10 стартов ≥ 8 из 10.
6. **CAD и схемы** — башенка: два светодиода, перегородка, центральный приёмник на корпусе; схема станции на RP2350-Zero; комплектация; журнал; README.
