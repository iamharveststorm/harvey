# Харви-помощник: время, таймеры, напоминания, память — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** «Харви, который час?», «поставь таймер на десять минут», «напомни через полчаса выключить чайник», «напомни в 18:30 позвонить маме», «сколько осталось?», «отмени таймер», «меня зовут Аня», «запомни, что я люблю чай», «что ты обо мне знаешь?», «забудь всё обо мне» — работают без LLM и без интернета; напоминание срабатывает само, даже если Харви «спит»; имя и факты помнятся между запусками и подсказываются LLM.

**Architecture:** В `код/мозг/harvey_brain/`: `numbers.py` (русские числа словами и цифрами → длительность / время суток), `assistant.py` (`Assistant.handle(text, wall) -> Reply | None` и `due(wall) -> list[Reply]`), `memory.py` (`Memory` — JSON-файл: имя, факты, таймеры). `Dialog._answer`: быстрые команды тела → `Assistant.handle` → LLM. `OllamaChat` получает строку о человеке из `Memory` в системное сообщение. `__main__` раз в 0,5 с спрашивает `assistant.due(time.time())` и отдаёт сработавшее как обычный ответ (голос + глаза голове).

**Tech Stack:** Python stdlib (json, datetime, re), pytest; venv `C:\venvs\harvey-brain`.

**Spec:** этот документ; решения — ведущего.

## Global Constraints
- Всё локально. Файл `~/.harvey/memory.json` (каталог как у моделей: `HARVEY_HOME`, иначе `~/.harvey`), не в репозитории; запись атомарная (временный файл + `os.replace`); битый файл — не падение, а пустая память и `memory.json.broken` рядом.
- Часы подменяются в тестах: стена — `wall: float` (epoch, местное время через `datetime.fromtimestamp`), монотонные — как сейчас в `Dialog`.
- Ответы — по-русски, коротко, с правильными окончаниями («1 минута», «2 минуты», «5 минут»; «1 час», «2 часа», «5 часов»; «1 секунда», «2 секунды», «5 секунд») — функция `plural(n, one, few, many)`.
- Код — по `.claude/skills/ub-mode/SKILL.md` (падающий тест первым). Тесты: `C:\venvs\harvey-brain\Scripts\python.exe -m pytest -q tests` из `код/мозг`; прежние 142 зелёные.

## Review Focus
1. Числа словами из распознавания: «двадцать пять минут», «полтора часа», «полчаса», «одну минуту», «пару минут» (= 2) (задача 1).
2. «Напомни в 7» вечером (сейчас 20:00) — завтра в 7:00, а не «в прошлом»; «в 7 вечера» — 19:00 (задача 1).
3. Харви выключали — при запуске напоминание, время которого прошло, срабатывает с «Пока меня не было: …», а не теряется и не срабатывает дважды (задача 3).
4. «Отмени таймер», когда таймеров два — отменяет ближайший и говорит, какой остался; когда нет — «Таймеров нет» (задача 2).
5. «Таймер» без числа — «На сколько поставить таймер?» и следующая фраза с длительностью ставит его (Харви ещё не уснул) (задача 2).

### Task 2: Помощник и память
**Files:** Create `harvey_brain/memory.py`, `harvey_brain/assistant.py`; Tests `tests/test_memory.py`, `tests/test_assistant.py`.

**Produces:**
- `Memory(path: Path)`: `name: str | None`, `facts: list[str]`, `timers: list[dict]` (`{"id": int, "due": float, "text": str | None, "seconds": float | None}`); `load()`, `save()`; `about() -> str` — «Человека зовут Аня. Он рассказывал: любит чай; …» (не больше 20 последних фактов), пусто — «».
- `Assistant(memory: Memory)`; `handle(text: str, wall: float) -> Reply | None` (текст — нормализованный остаток после «Харви»):
  - «который час», «сколько времени» → «Сейчас 14:05.»; «какое сегодня число», «какой сегодня день» → «Сегодня среда, 5 ноября.»
  - «таймер на …», «поставь таймер …», «засеки …» → «Ставлю таймер на 10 минут.» (`happy`); без длительности → «На сколько поставить таймер?» (`curious`) и следующая фраза с длительностью в течение 30 с (по `wall`) ставит его.
  - «напомни через … <текст>» и «напомни в … <текст>» → «Хорошо, напомню в 18:30: позвонить маме.»; без текста — «Хорошо, напомню через 20 минут.»
  - «сколько осталось» → по ближайшему: «Осталось 7 минут.»; нет — «Таймеров нет.»
  - «отмени таймер», «отмени напоминание» → отменяет ближайший: «Отменил. Остался таймер на 18:30.» / «Отменил.»; «отмени все таймеры» → все; нет — «Таймеров нет.»
  - «меня зовут <имя>» → «Приятно познакомиться, Аня!» (`love`); «как меня зовут» → «Тебя зовут Аня.» / «Ты ещё не сказал, как тебя зовут.»
  - «запомни что <факт>» / «запомни <факт>» → «Запомнил.»; «что ты обо мне знаешь» → имя и до 5 фактов; «забудь всё обо мне» → чистит имя и факты (таймеры остаются) → «Хорошо, забыл.»
  - иное → None (дальше — LLM).
  - Каждое изменение — `memory.save()`.
- `due(wall: float) -> list[Reply]` — сработавшие (`due <= wall`), удаляет их и сохраняет: таймер — «Динь! Прошло 10 минут.» (`surprised`), напоминание — «Напоминаю: позвонить маме.» (`curious`); если просрочено больше чем на 60 с — «Пока меня не было: …».
