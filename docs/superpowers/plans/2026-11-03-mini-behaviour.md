# Поведение «Компакт мини» в симуляции по своим датчикам — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Харви в MuJoCo ведёт себя только по своим датчикам: идёт домой по ИК-маяку, уходит от края, осматривается, подходит к руке, отпускает приводы, когда его подняли.

**Architecture:** Имитации датчиков (лучи VL53L4CD, ИК-приёмники, IMU, INA226, шины приводов) подключаются к **настоящему** `Spine` из прошивки RP2350 — так в симуляции работают `edge.py`, `reflex.py`, `beacon.py`, `imu_events.py` и протокол `link.py` без изменений. Поведение — чистый модуль головы (`harvey_head/behavior.py`): получает телеметрию и события, отдаёт команду корпусу. Связка «команда → походка → цели суставов → `j`» в симуляции заменяет будущий модуль походки головы.

**Tech Stack:** Python 3.14, MuJoCo, pytest; окружения `C:\venvs\harvey` (симуляция), `C:\venvs\harvey-head` (голова).

**Spec:** описание в разговоре от 03.11.2026, одобрено пользователем («всё верно, делай»): датчики в симуляции → настоящий код прошивки; поведение — отдельный модуль, который переедет в голову; 4 сценария (домой по маяку, у края, осмотреться, подойти к руке с заглушкой зрения по кадру 100°), «подняли — отпустить приводы»; тесты с нормами; числа, которых нет в даташитах, — «предварительно».

## Global Constraints

- Прошивку RP2350 (`код/прошивка/rp2350/*.py`) не менять ради симуляции: имитации подстраиваются под её интерфейсы (`EdgeArray(make=…)`, `imu.read() → (acc g, gyr °/с)`, `ina.volts()/amps()`, `beacon.take() → (L, R)`, `bus.sync_write(reg, {id: pos})`, `bus.release_all()`).
- Протокол — `link.py`: `v` в мм/с и °/с; ID = 10 × конечность + сустав (схемы/README.md «Номера приводов»): LF 1, LM 2, LB 3, RF 4, RM 5, RB 6, клешни L 7, R 8 (суставы y p e g = 1–4), глаза 91, 92; ноги c f k = 1–3.
- Позиция STS: 4096 на оборот, 2048 — ноль сустава (предварительно: нули задаются при сборке).
- Числа датчиков — из `документы/`:
  - TSAL6200: Ie тип. 72 мВт/ср при 100 мА, угол половинной силы ±17° (стр. 2);
  - TSOP382: Ee min до 0,25 мВт/м² (NEC, макс.), Ee max 30 Вт/м², половинная дальность ±45° (стр. 2–3);
  - маяк: пик 105 мА, 508 пачек/с (схемы/README.md «Станция»).
- Модель угловых кривых — `cos^n` по этим точкам (LED n = 15,9; приёмник — чувствительность ∝ cos⁴, т. к. дальность ∝ √E) — **предварительно, проверить на стенде**.
- Геометрия датчиков края — как `edge_seen` в `harvey_mini_teleop.py` (передние/задние 2,3 : 1, боковые 3,5 : 1); ИК-приёмники — `ir_axis` из CAD; камера — `harvey_eye` (x 66,2 мм, поле ≈ 100° по горизонтали).
- Правила кода: ub-mode (тест → минимум → чистка), CRAP < 10, без дублей ≥ 0,8; пути к файлам вне папки в тестах — и с `absolute()`, и с `resolve()`.

## Review Focus

1. Маяк сзади станции (башенка заслоняет) — поведение не крутится бесконечно, а сообщает «не вижу станцию» после полного оборота.
2. Край во время захода на станцию или осмотра — рефлекс `Spine` всё равно останавливает; поведение уходит в «у края».
3. Подняли посреди любого сценария — приводы отпущены, после возвращения на стол поведение начинает с «осмотреться», а не продолжает старую команду.
4. Рука вышла из кадра при подходе — остановиться и искать, а не идти по последнему направлению.
5. Контакты станции не замкнулись после «лечь» — встать, отойти и повторить заход один раз, потом сдаться.

### Task 4: поведение (голова)

**Files:**
- Create: `код/голова/harvey_head/behavior.py`
- Test: `код/голова/tests/test_behavior.py`

**Interfaces — Produces:** `Behavior(now: float)`; `.update(tel: dict, events: list[str], vision: dict | None, now: float) -> dict` → `{"v": (vx, vy, wz), "pose": "stand"|"lie", "state": str}`; `.request(goal: "home"|"look"|"hand")`; `.state: str`.

Состояния и правила (числа — мои, предварительно):
- `look`: поворот 40 °/с по кругу, 6 остановок по 1 с; рука в кадре → `hand`; круг пройден → `idle`.
- `hand`: поворот к `bearing_deg` (|угол| > 8° — поворот 30 °/с × знак), идти 40 мм/с, стоп при `dist_mm ≤ 90`; рука пропала > 0,5 с → `look`.
- `edge` (событие `edge` или `far` в сторону движения): назад 30 мм/с 1,5 с, поворот на 120° (по времени), затем прежняя цель.
- `home`: `search` — поворот 30 °/с, пока `beacon == "none"`, полный оборот без маяка → `lost`; `center` — проход сектора «ahead» на 20 °/с: время входа и выхода, поворот назад на половину; `approach` — вперёд 40 мм/с с повторным центрированием каждые 4 с; `climb` — тангаж вырос ≥ 1,5° (передние ноги на площадке) → ещё 1,6 с вперёд → ровно (|тангаж| < 0,8°) → `lie`; `lie` → событие `docked` или ток < −50 мА за 3 с → `docked`, иначе один повтор: встать, назад 2 с, снова `search`; второй раз → `failed`.
- `lifted` → `pose: relax`-ожидание, без движения; все `far == 0` 1 с подряд → `look`.
- `bat_low` → `home`.
