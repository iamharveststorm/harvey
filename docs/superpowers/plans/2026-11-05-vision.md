# Зрение на ПК: лица — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Мозг находит лицо в кадре камеры головы (или камеры ноутбука): глаза Харви следят за лицом; человек появился после долгого отсутствия — «Привет!» (с именем, если оно в памяти); «Харви, посмотри на меня», когда лицо видно, — Харви поворачивается к человеку корпусом. Кто это — не узнаём (только «есть лицо»).

**Architecture:** `код/мозг/harvey_brain/vision.py`: `FaceFinder` (OpenCV `FaceDetectorYN`, модель YuNet `~/.harvey/models/vision/face_detection_yunet_2023mar.onnx`), чистая геометрия (направление на лицо по матрице камеры головы `harvey_head.dock_tag.camera_matrix(*FRAME)`), `Watcher` — состояние «видно / не видно», сглаживание, приветствие. Источник кадров — `MediaServer.latest_frame()` (серый JPEG 1280×720 с головы) или `cv2.VideoCapture` (`--webcam`). Голове — `{"t": "look", "x", "y"}` и новое `{"t": "turn", "deg": d}` → `Body.request("turn", now, deg=d)` → состояние поведения `turn` (поворот на месте по гироскопу через уже существующий `Behavior.turn_to`, затем `idle`).

**Tech Stack:** OpenCV 5.0 (`opencv-python-headless` 5.0.0.93 в `C:\venvs\harvey-brain`), numpy 2.5.4.

**Spec:** этот документ; решения — ведущего.

## Global Constraints
- Модель и тестовые картинки — вне репозитория: `~/.harvey/models/vision/` (`HARVEY_MODELS`), тесты с ними пропускаются, если файлов нет. Тестовые картинки: `test/messi5.jpg` (одно лицо), `test/fruits.jpg` (лиц нет); `lena.jpg` в тестах **не использовать**.
- `requirements.txt` мозга: добавить `opencv-python-headless==5.0.0.93`.
- Серый кадр → BGR (`cv2.cvtColor(GRAY2BGR)`) перед YuNet; порог уверенности 0,8.
- Знаки углов — как у метки станции (`dock_tag` / `behavior.home_face`): проверить по коду и закрепить тестом (лицо в правой половине кадра → поворот в ту же сторону, что для метки в правой половине).
- Камеру ноутбука в тестах не открывать; `--webcam` проверяет пользователь сам.
- Голову менять только в объёме задачи 2. TDD по `.claude/skills/ub-mode/SKILL.md`; CRAP < 10. Тесты голова / мозг — как в CLAUDE.md.

## Review Focus
1. Лицо мигает (то видно, то нет на 1–2 кадра) — нет дёрганья глаз и повторных «Привет!»: «пропало» только после 3 с без лица (задача 1).
2. Несколько лиц — следить за самым крупным (ближайшим) (задача 1).
3. Кадра давно нет (голова отключилась) — Watcher не считает старый кадр «лицом сейчас»: кадр старше 1 с игнорируется (задача 3).
4. «Посмотри на меня», когда лица не видно — как раньше (осмотреться, `look`) (задача 3).
5. Поворот на 170° и −170° — поворот короткой дорогой, не через 340° (задача 2).

**Produces:** `Face` (dataclass: `x, y, w, h, score`); `FaceFinder(model_path: Path, score: float = 0.8)` — `find(img: np.ndarray) -> list[Face]` (серый или BGR; по убыванию площади); `decode(jpeg: bytes) -> np.ndarray | None`; `direction(face, K: np.ndarray) -> tuple[float, float]` — (азимут°, угол места°) центра лица по матрице камеры; `gaze(face, width, height) -> tuple[float, float]` — для `look`: x, y в [-1, 1]; `class Watcher(away_s: float = 600.0, lost_s: float = 3.0, alpha: float = 0.5)` — `update(faces: list[Face], now: float, K, size) -> list[dict]` (сообщения голове: `look` не чаще 5 раз в секунду, сглаженный; при потере лица на `lost_s` — один `look` 0,0), `appeared -> bool` (флаг «пора здороваться», сбрасывается чтением `take_greeting() -> bool`), `bearing -> float | None` (азимут текущего лица).
